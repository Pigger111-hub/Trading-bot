## Shared public interfaces (freeze before delegation)

`lab3.store.Store(root)` where root is repository root. `root/phase3/state/lab.sqlite`.
- `append(kind: str, payload: dict) -> dict` returns event `{id,kind,payload,prev_hash,hash,created_at}`; canonical UTF8 JSON SHA256; transaction/append-only triggers; reject nonfinite JSON.
- `events(kind: str|None=None) -> list[dict]` verifies full chain before returning; connections explicitly close.
- `put(collection: str, item: dict) -> dict`: canonical immutable revision via event kind `item_saved`, payload `{collection,item}`. Valid collections: `sources,cards,gaps,hypotheses,queue,lessons,cycles`. Item must have nonblank `id`; each new revision adds integer `version` and `previous_version_hash`; never UPDATE historical rows. Snapshot takes latest version per collection/id. Reject identical duplicates without a new revision. User-controlled extra fields are data only.
- `snapshot() -> dict`: `{available:true,integrity:{verified:true,event_count:int,head_hash:str},sources:[],cards:[],gaps:[],hypotheses:[],queue:[],lessons:[],cycles:[],safety:{execution_enabled:false,scheduler_enabled:false,credentials_enabled:false},counts:{...collection lengths...}}`; collections latest documents.
- `Store.read_snapshot(root) -> dict` static/class method: opens existing DB URI mode=ro + PRAGMA query_only. MUST NOT initialize/create/mkdir/schema or journal files. Missing DB returns same empty arrays/counts with `available:false, integrity:{verified:false,event_count:0,head_hash:null}`. Corruption raises `IntegrityError(ValueError)`. Verify and project in one consistent read transaction. Paths local fixed, no API caller-selected DB.
- `reserve_model_call(cycle_id,role,cap=3) -> dict` atomically validates cycle active, counts reservations, reserves BEFORE call; failed calls consume cap, bool/non-int cap rejected; hard maximum3; roles `research_planner,knowledge_researcher,independent_critic`.
- `start_cycle() -> dict`: one active cycle only, creates RUNNING cycle item with UUID id, prevents overlap atomically. `finish_cycle(cycle_id,status,details)` status `COMPLETED|FAILED|INTERRUPTED`; marks versioned status, validates active identity. Recovery is explicit, never replay completed model calls automatically.

`lab3.planning`:
- `validate_hypothesis(item,source_ids)` validates fields: id, family in `trend_following|momentum|mean_reversion|volatility`, title_th, hypothesis_th, entry_logic, exit_logic, falsification, parameters (finite, bounded declarative dict), source_ids nonempty subset, scores `{evidence_quality,novelty,information_gain,complexity}` exact integers1..5 (not bool). No Python code execution, no strategy compilation. Reject invalid/missing schemas and unsupported families.
- `rank_hypotheses(items) -> list`: deterministic descending `3*evidence_quality+2*novelty+3*information_gain-2*complexity`, tie id; expose score and explicitly heuristic/not expected profits or calculated mutual information.
- `verify_original_baseline(root)` pins strict canonical parsed manifest content (portable LF/CRLF), verifies all 56 protected file byte hashes, rejects duplicate JSON keys/path escapes/semantic tampering, and returns `{verified:true,file_count:56,manifest_sha256:<canonical digest>}`. Original evidence is never reformatted.
- `exposed_windows(root) -> list[dict]`: verify `dashboard/qa/baseline-evidence.json` protected files then read original manifest window; use entire already-viewed dataset window, not only holdout. Include original data/holdout exposures from read-only original DB plus any new phase3 exposure events; overlapping half-open windows rejected independent of UUID/hash.
- `assert_fresh_window(start,end,exposures)` strict aware UTC ISO timestamps, end>start, rejects any overlap, returns true; touching end/start allowed. No future-data freshness claims: absence of exposure != availability/validation.
- `make_plan(hypothesis,root) -> dict`: fixed BTCUSDT spot1h long-only leverage1; cash10000, position_fraction0.1; metrics return/annualized/MDD/Sharpe/winrate/tradecount; Cash and BH10 matched initial capital/allocation, BH100 context; commission0.001 spread0.0005 scenario, doubled-cost sensitivity all planned validation scopes. Minimum30 closed trades else INSUFFICIENT. Predeclared chronological dev/validation/holdout windows after known exposure end; include explicit `data_status:UNAVAILABLE_UNVERIFIED`, all execution gates false, `engine_evaluations_consumed:0`, proposed max2configs/max10evaluations (not approved). Explicit deterministic method/timing/warmup and no holdout tuning. If planned split overlaps known exposure, reject.
- `transition_proposal(store,id,target,actor,reason)` latest queue statuses `PROPOSED|APPROVED|RUNNING|COMPLETED|REJECTED`; only PROPOSED->APPROVED/REJECTED or APPROVED->REJECTED human (`actor='human'`, nonblank reason); APPROVED is DESIGN_ONLY, never permission to run. RUNNING/COMPLETED always forbidden in Phase3. Model cannot call this. Plans immutable version-bound; approval binds proposal hash. Critical/rejected critic cannot become APPROVED.

## Research controller ownership

`lab3.sources` imports only store stdlib/planning if needed. New source catalog candidates are independently verified against Crossref DOI metadata, classified `VERIFIED_METADATA_PENDING_HUMAN_APPROVAL`; Crossref presence is not scientific credibility or full-text validation. No autoactivation. Manual source approval preserves review history. Metadata-only approval does not activate document retrieval. A separately human-requested verification command may fetch an explicitly supplied public HTTPS document/redirect allowlist into QUARANTINED_DOCUMENT_TEXT, never active knowledge. Require DOI/title association plus hash-checked raw/text snapshots, and another explicit human exact-document approval before future cycles may use that frozen snapshot. Association is a heuristic, not scientific credibility. Refresh requires quarantine/reapproval; rediscovery cannot silently replace approved document bytes. Cards bind source revision/item hash/raw SHA/text SHA, not merely source ID. Approved seeds bootstrapped from exact reviewed original CATALOG URLs, with original file hash verified. Fetch only exact approved HTTPS URLs (validate each redirect, credentials/ports/private addresses rejected, no inherited proxy/netrc). All network response/timeout/redirect/bytes/request counts bounded. Save hashes, retrieval times, original requested/final URL, original metadata/text snapshots. No arbitrary candidate URL is fetched automatically; DOI links remain pending. Discover all four families via Crossref query API (trusted transport metadata, NOT automatically approved academic claims). Search results, documents and model outputs are untrusted data. Discover max4queries/max3results each; total max12 actual HTTP requests per cycle, max1MB per response, no unbounded retries.

`lab3.models.HermesModel`: actual `hermes chat --oneshot --query-file - --format stream-json --safe-mode --toolsets bot_room --max-turns 1 --run-budget 135 --reasoning low --provider openai-codex --model gpt-6.1-sol`. Verify installed help/toolset if needed. Subprocess shell=False, bounded150s, fresh scratch cwd explicitly under Hermes cache/scratch, sanitized exchange env. Reserve model call BEFORE execution. Strict JSON parser rejects nonfinite, unexpected tool events, unsuccessful/missing/duplicate result, missing output; no fabricated fallback. Audit usage/role/prompt hash and actual response. Three separate roles/fresh contexts, maximum3 calls. This is trusted controller hygiene, not adversarial OS isolation.

`lab3.research.run_cycle(root,model=None,fetcher=None)`:
1. Verify original baseline unchanged; start single active persistent cycle.
2. Read existing knowledge gaps/cards and Batch001 independent review/metrics as evidence (bounded); never run engine. Import summaries as scoped prior findings, not new performance.
3. Planner (call1) chooses autonomous questions/queries across four families based on gaps/prior failures. User need not supply strategy/topic. Persist planner result.
4. Discover bounded Crossref metadata candidates; fetch max2 exact reviewed seed documents, store approved source text snapshots. Store metadata candidates as pending approval, not trusted claims. Retain actual network failures, no fabricated content.
5. Researcher (call2) creates 1..4 Thai knowledge cards with exact source quotes (<=25 English words/source across whole report outputs preferred), uncertainties/new gaps, four declarative hypotheses covering families, lessons/method proposals. Source IDs valid and quotes must literally occur in source text. Unsupported/nonfinite/missing schema fail closed. A card with pending metadata cannot be elevated to verified full-text evidence.
6. Critic (call3) reviews source support, novelty, splits/costs/overfitting/implementation feasibility, not profitability. Strict `{verdict:'ACCEPT_AS_PROPOSAL'|'REVISE'|'REJECT',issues:list[str],lessons_th:list[str],next_questions:list[str]}`. Accept only issues explicitly empty; all verdicts persisted, no suppression of failures.
7. Persist versioned cards `EVIDENCE_BACKED_CLAIM` only with accepted critic and literal quote support; rejected outputs preserved as rejected drafts/events, not facts. Persist hypotheses, critique, heuristic rank, plans and queue PROPOSED if accepted, otherwise REJECTED. Always keep human approval/execution gates false and distinguish proposal from experiment.
8. Persist lessons/gaps/summary, finish COMPLETED and STOP after exactly one foreground cycle. No backtest, code generation execution, schedule or source approvals. On any failure record FAILED and exit nonzero; preserve intermediate evidence/reservations for explicit recovery.

CLI: `python -m lab3.cli --root <repo> run` (one cycle only); `status`; `recover --reason`; human-only `approve-source`/`approve-proposal`/`reject-proposal` with reviewer/reason. No execute/backtest/scheduler CLI exists. README clearly explains same-OS-user authority limits; model has no tools/approval path, not cryptographic human authentication.
